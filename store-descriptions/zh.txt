JSON Toolbox 会把 浏览器 以纯文本 <pre> 形式展示的、难以阅读的原始 JSON 变成真正的查看器——自动生效、适用于任何页面，无需任何点击。

工作方式
安装后，打开任意返回 JSON 的网址即可。如果整页就是一个合法且完整的 JSON 文档，查看器会自动全屏替换原始文本。在其他所有页面（博客、文档、GitHub、仪表盘）上，扩展什么都不做——不弹窗、不通知、不改动 DOM。随时点击工具栏图标，即可在独立标签页中重新打开最近一次预览的 JSON，也可以直接粘贴 JSON 从零开始处理。

功能
• 分栏编辑器 + 树视图：CodeMirror 6 语法高亮、行号、撤销/重做；节点可编辑（重命名、改类型、增删移动、批量赋值），并提供 100 步历史记录。
• 对象数组专用表格视图：显示/隐藏列、点击表头排序、导出 CSV。
• 搜索：支持键、值、路径、全部内容或 JSONPath。带结果抽屉、循环切换上一个/下一个、Enter / Shift+Enter、Esc 清除、Ctrl/Cmd+F。搜索做了防抖和上限控制，长树在滚动时逐步渲染。
• 值洞察：颜色、时间戳、JWT、Base64、UUID、IP、Markdown、URL 和邮箱；图片 / 音频 / 视频 / PDF 预览，灯箱支持键盘导航，可单张或批量下载。
• Raw / 树切换，复制值 / 路径 / JSONPath / 整个文档，下载为文件，状态栏显示错误行列号。
• 同样支持本地 .json 文件（需要在扩展详情页开启“允许访问文件网址”）。

设置
⚙ 面板可选择主题（浅色 / 深色 / 自动）、缩进（2 / 4 / Tab）、默认视图、语言（English / 中文 / 日本語 / Français / Español / Deutsch）、媒体预览，以及自动美化的总开关。更改会立即作用于已打开的查看器，并仅保存在本机。

隐私
所有解析、编辑、格式化和搜索都在浏览器本地完成。没有账号、没有遥测、没有分析、没有远程脚本或字体，也没有我们的服务器接收你的 JSON。你的设置和最近一次预览的 JSON 文本只保存在本机的 browser.storage.local 中，卸载扩展后即消失。

需要留意：当“预览图片和媒体”开启时（默认开启），JSON 中的 URL 会被浏览器作为 <img>、<audio>、<video> 或 <iframe> 加载，因此这些请求会发到对应资源的服务器。“全部下载”同样会请求这些 URL。关闭该开关即可禁用所有第三方请求；内联的 data:/base64 图片永远不会发起请求。指向 jsontoolbox.cc 的链接、支持链接和反馈链接都只在你点击时才打开。

权限
• storage —— 在本地保存你的设置和最近预览的 JSON。
• 所有网站的内容脚本 —— 浏览器 没有根据响应内容类型注入的 API，因此自动检测需要宽泛的匹配规则。脚本只读取已有的 <pre> 文本，在内存中解析并渲染到 Shadow DOM；在非 JSON 页面会直接退出，不触碰页面内容。不申请任何 host_permissions。
• file:///* —— 对本地 .json 做同样的检测；需要你在 浏览器 中手动授权。

超过 2 MiB 的文档会被跳过。扩展会刻意避开 jsontoolbox.cc 和 www.jsontoolbox.cc，不影响站点自带的工具。
