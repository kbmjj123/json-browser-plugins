JSON Toolbox は、Chrome がプレーンテキストの <pre> として表示する読みにくい生 JSON を、正式なビューアに変換します。自動で、どのページでも、クリック不要です。

仕組み
インストール後、JSON を返す任意の URL を開いてください。ページ全体が 1 つの有効な JSON ドキュメントの場合、全画面ビューアが生テキストに代わって表示されます。それ以外のページ（ブログ、ドキュメント、GitHub、ダッシュボードなど）では、拡張機能は何もしません。ポップアップも通知も DOM 変更もありません。ツールバーのアイコンをクリックすれば、最近プレビューした JSON を専用タブでいつでも再表示できます。そこに JSON を貼り付けて新規に作業することもできます。

主な機能
• 分割エディター + ツリー：CodeMirror 6 の構文強調表示、行番号、元に戻す/やり直し、ノード編集（名前変更、型変更、追加/削除/移動、一括値設定）、100 ステップの履歴。
• オブジェクト配列向けテーブル表示：列の表示/非表示、ヘッダークリックで並べ替え、CSV エクスポート。
• 検索：キー、値、パス、すべて、JSONPath に対応。結果ドロワー、前/次の循環移動、Enter / Shift+Enter、Esc でクリア、Ctrl/Cmd+F。検索はデバウンスと上限をかけており、長いツリーはスクロールに合わせて段階的に描画されます。
• 値のインサイト：色、タイムスタンプ、JWT、Base64、UUID、IP、Markdown、URL、メールアドレス。画像 / 音声 / 動画 / PDF のプレビューはキーボード操作可能なライトボックス対応で、単一画像と一括ダウンロードが可能です。
• Raw / Tree 切り替え、値 / パス / JSONPath / ドキュメント全体のコピー、ファイルとしてダウンロード、エラー行と列を表示するステータスバー。
• ローカルの .json ファイルにも対応（Chrome の拡張機能詳細ページで「ファイル URL へのアクセスを許可」を有効にする必要があります）。

設定
⚙ パネルでテーマ（ライト / ダーク / 自動）、インデント（2 / 4 / タブ）、既定のビュー、言語（English / 中文 / 日本語 / Français / Español / Deutsch）、メディア プレビュー、自動整形のマスター スイッチを設定できます。変更は開いているビューアに即時反映され、端末内に保存されます。

プライバシー
解析、編集、整形、検索はすべてブラウザー内で行われます。アカウント、テレメトリ、アナリティクス、リモート スクリプトやフォントはなく、当方のサーバーが JSON を受け取ることもありません。設定と最後にプレビューした JSON テキストは、この端末の browser.storage.local にのみ保存され、拡張機能を削除すると消えます。

ご注意ください：「画像とメディアをプレビュー」がオンの場合（既定はオン）、JSON 内の URL がブラウザーによって <img>、<audio>、<video>、<iframe> として読み込まれるため、そのリクエストは当該 URL をホストするサーバーに送信されます。「すべてダウンロード」も同様に URL を取得します。スイッチをオフにするとすべてのサードパーティ リクエストが無効になります。インラインの data:/base64 画像はリクエストを送信しません。jsontoolbox.cc へのリンク、サポート リンク、フィードバック リンクは、クリックしたときだけ開きます。

権限
• storage — 設定と最近プレビューした JSON をローカルに保存します。
• すべてのサイトのコンテンツ スクリプト — Chrome にはレスポンスの Content-Type に基づいて注入する API がないため、自動検出には広い一致パターンが必要です。スクリプトは既存の <pre> テキストのみを読み取り、メモリ内で解析してシャドウ ルートに描画します。JSON 以外のページではページに触れずに終了します。host_permissions は要求しません。
• file:///* — ローカル .json でも同じ検出を行います。Chrome で手動の許可が必要です。

2 MiB を超えるドキュメントは対象外です。拡張機能は jsontoolbox.cc と www.jsontoolbox.cc を意図的にスキップするため、サイト独自のツールには影響しません。
